# 02 — Logo System

Downloads: `static/brand/logo/` · Board: `/brand-kit/#logo`

All lettering in the downloads is converted to outlines, so the files render identically without Anton or Oswald installed.

## Lockups

| File | Lockup | Use |
|------|--------|-----|
| `rip-primary.svg` | RIP / TEQUILA / REST IN PROOF (stacked) | Main moments, posters, packaging fronts, hero, brand book |
| `rip-primary-reverse.svg` | Same, Bone Cream on Obsidian | Dark packaging, apparel, night campaigns |
| `rip-primary-gold.svg` | Black + Antique Gold | Limited editions, seals, boxes, reserve |
| `rip-horizontal.svg` | RIP TEQUILA one line | Headers, banners, packaging sides, mobile |
| `rip-badge.svg` | Circular badge — RIP TEQUILA / REST IN PROOF | Seals, coasters, patches, stickers, avatars |
| `rip-monogram.svg` | R†P — cross as the I | Caps, wax seals, embroidery, small icons |
| `rip-neck-seal.svg` | Vertical neck-label | Bottle seals, batch tags |
| `rip-favicon.svg` | Simplified RIP monogram | Favicon, social icons, tiny spots |

Structure: **RIP** stacked over **TEQUILA**, optional **REST IN PROOF** subline. Agave spikes flank on hero sizes. No tombstone icon, halo, or skeletal-hand graphic in the shipped mark — typography carries the brand.

## Color versions

- **Primary:** Black #0D0D0D on Bone Cream #F2EDE0 — most applications
- **Reverse:** Bone Cream on Black — dark packaging, apparel, night materials
- **Accent:** Black + Red #B22222 cross + Green #2E7D4F agave — posters, labels, social
- **Premium:** Black + Gold #C6A24A — limited editions, seals, boxes
- **One-color:** Solid Black or Solid Cream — stamps, embroidery, screenprint, small merch

## Clear space & minimum sizes

Clear space: height of the `I` in RIP on all sides.

| Mark | Print min | Digital min |
|------|-----------|-------------|
| Primary | 1.5" wide | 220px wide |
| Badge | 0.75" wide | 96px wide |
| Monogram | 0.4" wide | 48px wide |

## Do / Don't

**Do:** Use approved colors · keep it bold and readable · let it breathe · pair with simple backgrounds · keep agave clean.

**Don't:** Stretch or squash · add drop shadows or gradients · use random colors · overcrowd with skulls · rotate unnecessarily · use on busy photo backgrounds · make it ornate/horror · mix with thin-line icon styles.
