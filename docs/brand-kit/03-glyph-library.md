# 03 — Glyph Library (47 glyphs)

Engine: `layouts/partials/glyph.html` · Styles: `assets/scss/components/_glyphs.scss` · Downloads: `static/brand/glyphs/*.svg`
Grid: 24×24, 2px strokes, heavy fills, `currentColor` + `fill-opacity 0.15` wash. Sizes: xs 0.85rem → hero clamp(5.5rem–10rem).

## Construction

Flat, bold, slightly distressed cut-paper. Build clean, distress after. Three detail levels: Tiny (seals/footers), Standard (posters/social), Hero (merch/cards). One hero glyph per layout. Pair with short copy. Use as dividers, seals, repeating patterns.

Color rule: one color, or Black+Green, Black+Red, Black+Gold, Cream reversed on Black. Never more than three colors in one glyph.

## Do / Don't

**Do:** Keep weight consistent · one hero per layout · pair with short copy · build patterns from the library.
**Don't:** Mix icon styles · thin-line icons · realistic shading · random clipart · overload layouts · use sacred imagery as punchline · make skulls scary · turn every joke into a death joke.
