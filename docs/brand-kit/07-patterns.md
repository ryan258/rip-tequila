# 07 — Patterns

Downloads: `static/brand/patterns/*.svg` — tileable, single-color `currentColor` so they inherit theme.

| File | Glyphs | Use |
|------|--------|-----|
| `pattern-ritual.svg` | glass, lemon, salt dots, bottle, agave | Tissue, box interiors, bar mats, site backgrounds |
| `pattern-afterlife.svg` | skull, monument, candle, cross, coffin-line | Stickers, limited drops, posters, matchbooks |
| `pattern-cantina.svg` | bell, microphone, maracas, rose, candle | Character merch, party flyers, social templates |
| `pattern-desert.svg` | cactus, moon, sun, eye, wind | Side panels, apparel, section backgrounds |

Rules: build from the glyph library at consistent weight. Keep contrast low (wash at 0.15 or single-color line). Never more than one pattern field per layout. Pattern is background, never headline. Footer strips: glyph row under back-label copy.

Construction: 400×400 viewBox, 80px grid, glyphs 32px, 48px gutters. Stroke inherits `currentColor`; wrap in a container with `color: #0D0D0D` on cream or `#F2EDE0` on black.

## Do / Don't
**Do:** tile at low opacity · let type sit on top clear · reuse Ritual for packaging interiors.
**Don't:** full-color rainbow patterns · photo backgrounds behind patterns · three patterns on one spread · shrink glyphs below 24px in pattern use.
