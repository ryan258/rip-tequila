## Bottle label

Front hierarchy: small cross/skull → RIP TEQUILA → hero glyph → variant (BLANCO / REPOSADO / AÑEJO / EXTRA AÑEJO) → REST IN PROOF → SAVE WATER, DRINK TEQUILA! → footer (Fictional Parody Spirit · 750 ML — never an ABV, proof, or agave-percentage line). Back label: badge, short myth, character quote, batch detail, responsible disclaimer, glyph row.

Bottle: short-to-medium, broad-shouldered, squared, heavy-bottomed. Matte black / smoky glass, bone-cream paper label, spot gloss on RIP, gold foil for premium. No ornate skull bottles. No Halloween props.

Neck seal: monogram/skull-agave, variant stripe, batch number, REST IN PROOF. Blanco: cream/black · Reposado: red/black · Añejo: gold/black · Extra Añejo: black/gold · Midnight Agave: green/black.

Topper: matte black cork, debossed cross, skull-agave seal on top, red tax-strip band. Premium: gold top. Collector: numbered.

Box: tall rectangular, matte black or cream, large RIP, variant panel, character side, slogan band, interior repeating pattern. Case box: kraft/one-color black, large RIP, FRAGILE: CONTAINS BAD IDEAS · HANDLE WITH LIME · DELIVER TO: LA CANTINA DEL ÚLTIMO TRAGO.

## Merch

One large glyph + one strong phrase + minimal supporting text.

| Piece | Recipe | Best lines |
|-------|--------|------------|
| T-shirt | Hero glyph, phrase | Rest In Proof + skull/agave · The Dead Have Better Music |
| Coaster | Badge or lockup, one phrase | Rest In Proof · Proof You Lived · Here Lies Your Judgment |
| Matchbook | Candle + match + tiny mark | Light the candle. Ring the bell. |
| Sticker / patch | Badge, skull-agave | Shake Now. Explain Later. |
| Social avatar | Monogram / badge simplified | R†P |

Do: premium first, humor in details. Don't: clutter, skull overload, fake seals, certification marks, binge copy, real-label mimicry without parody mark.
