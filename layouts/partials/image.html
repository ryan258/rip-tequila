{{- /* with intrinsic width/height so the browser can reserve space before the file loads. Images live in assets/ rather than static/ precisely so Hugo can read their real dimensions here. dict keys: src (required, e.g. "images/cast/don-muerte.webp"), alt (required, "" for decorative), class, loading (default "lazy"), decoding (default "async"), sizes. Passing "sizes" (e.g. "90px") opts into resized webp derivatives, for slots far smaller than the source art — a 1254px portrait rendered at 30px is a megabyte of wasted download. Without it the original ships unchanged, which is correct for full-bleed heroes and detail shots. A missing file falls back to a plain tag rather than failing the build — front matter can point at art that hasn't landed yet. */ -}} {{- $src := .src -}} {{- $res := resources.Get $src -}} {{- $loading := .loading | default "lazy" -}} {{- $decoding := .decoding | default "async" -}} {{- if $res -}} {{- $srcset := "" -}} {{- if and .sizes (in (slice "png" "jpeg" "webp") $res.MediaType.SubType) -}} {{- $set := slice -}} {{- range (slice 160 320 640) -}} {{- if lt . $res.Width -}} {{- $d := $res.Resize (printf "%dx webp q80" .) -}} {{- $set = $set | append (printf "%s %dw" $d.RelPermalink .) -}} {{- end -}} {{- end -}} {{- $srcset = delimit ($set | append (printf "%s %dw" $res.RelPermalink $res.Width)) ", " -}} {{- end -}} {{- else -}} {{- warnf "partial image.html: no asset at %q" $src -}} {{- end -}}
